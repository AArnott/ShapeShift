# ShapeShift.Toml

## Features

* PolyType-based serialization means a shared set of attributes for your data models regardless of the use case.
* Serialize any object to TOML (Tom's Obvious, Minimal Language).
* Support for root tables, inline tables, arrays, comments, and quoted or bare keys.
* Native support for strings, integers, floats, booleans, and date-times.
* ShapeShift extensions for nulls and quoted .NET durations, which TOML does not define natively.
* Binary values are rejected because TOML has no binary scalar.
* Conformance-tested against the ShapeShift conformance suite.
